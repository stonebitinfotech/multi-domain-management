    What is proxy?

    It decides how visitors reach your server — shown as an orange or grey cloud.

    ProxiedOrange cloud
    Visitor Cloudflare Your server
    • Hides your real server IP address
    • Free SSL (https) and CDN caching — faster website
    • Blocks DDoS attacks and bad bots

    Use for: websites — @, www, blog, shop

    DNS onlyGrey cloud
    Visitor Your server
    • Points straight to your server IP
    • Works for every kind of service
    • No Cloudflare protection or caching

    Use for: mail, ftp, cpanel, SSH, VPS panels, game servers

    Keep email & FTP on DNS only. Proxy only carries website traffic (http / https). Mail, FTP, SSH and similar services stop working when proxied.
    In short: Website → Proxied. Email, FTP, servers → DNS only. Proxy is available for A, AAAA and CNAME records; MX, TXT and NS are always DNS only.
